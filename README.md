# 架空の介護派遣サービス「CareSend」のランディングページ

架空の介護派遣サービス「CareSend」のランディングページ1枚を、Figmaのデザインカンプから静的コーディングしました。  


## 特に力を入れた点
入力フォームの実装に力を入れました。具体的には以下の点です。
- 入力中の項目を視覚的に分かりやすくするため、フォーカス時に枠線を強調表示
- 必須項目がすべて入力されるまで送信ボタンを非活性化し、不備のある状態での送信を防止
- 送信完了後はボタンを非表示にし、完了メッセージを表示することで二重送信を防止
- ページ遷移を発生させずスムーズに送信できるよう、Ajaxを用いてGoogle Formsへ非同期送信


## ページ構成
トップページ1枚のみ


## デザインカンプ
`Figma`


## 使用した技術
- HTML/CSS/JavaScript
- Sass（Dart Sass）
- CSS設計（BEM/FLOCSS）


## 実装した機能およびUIパーツ
- ハンバーガーメニュー
- スムーススクロール
- 2枚同時スライダー（slickを使用）
- アコーディオン
- 入力フォームの必須項目がすべて入力されるまで送信ボタンを非活性化
- 入力フォームの入力情報をGoogle Formsに非同期送信（Ajaxを使用）
